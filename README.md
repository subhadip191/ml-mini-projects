# Machine Learning Mini Projects

A collection of machine learning, statistics, and data science projects created while learning and practicing core concepts through hands-on implementation.

This repository contains small projects and experiments covering data analysis, statistical modeling, dimensionality reduction, clustering, regression, regularization, and model evaluation.

## 📂 Projects

### 1. [Student Academic Outcome Analysis](student-academic-outcome-analysis/)

An exploratory and unsupervised learning study of student academic outcomes using **EDA, correlation analysis, PCA, and K-Means clustering**.

**Topics:**
`EDA` · `Data Analysis` · `PCA` · `K-Means` · `Clustering`

---

### 2. [Probability Distribution Simulation & Analysis](probability-distribution-simulation/)

A statistical simulation study of the **Poisson and Exponential distributions**, including theoretical analysis, random simulation, empirical moments, and a hospital emergency call-centre application.

**Topics:**
`Probability` · `Poisson Distribution` · `Exponential Distribution` · `Simulation` · `Statistics`

---

### 3. [Regression & Regularization Study](regression-regularization-study/)

A study of regression and statistical learning techniques covering **OLS, Ridge, Lasso, Elastic Net, polynomial regression, decision trees, and the bias-variance trade-off**.

**Topics:**
`Linear Regression` · `Ridge` · `Lasso` · `Elastic Net` · `Polynomial Regression` · `Decision Trees` · `Bias-Variance`
